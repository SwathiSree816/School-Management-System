# 🎓 School Management System

## Overview

The School Management System is a full-stack web application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). It is designed to simplify and digitize the daily operations of educational institutions by providing a centralized platform for administrators, teachers, students, and parents.

The application offers secure authentication, role-based access, attendance management, student and teacher management, and an efficient communication system through announcements and notices.

---

## Features

* Secure user registration and login
* JWT-based authentication and authorization
* Role-based access for Admin, Teacher, Student, and Parent
* Student management (Add, Update, Delete, View)
* Teacher management
* Attendance management
* Student and Teacher dashboards
* Parent dashboard
* Announcements and notices
* Responsive and user-friendly interface
